# 🔐 Password Generator

A strong **Password Generator** with customizable options and strength meter.

## Features
- Adjustable password length
- Include/exclude uppercase, lowercase, numbers, symbols
- Live strength meter
- Copy to clipboard button
- Clean modern UI

## How to Run
Open `index.html` in your browser.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
